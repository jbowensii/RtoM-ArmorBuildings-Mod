Place `app_icon.ico` here for the application and installer icon.

Requirements:
- Format: .ico (Windows icon)
- Sizes: 16x16, 32x32, 48x48, 256x256 (multi-resolution .ico)
- Once added, uncomment the icon lines in:
  - `build/RtoMModTools.spec` (PyInstaller exe icon)
  - `build/installer/RtoMModTools.iss` (installer icon)
