Overview

RtoM Mod Tools is a PySide6 desktop application for managing the Secrets of Khazad-Dûm mod for The Lord of the Rings: Return to Moria. The mod adds cosmetic armour sets and 28+ building/construction packs to the game.

The tool provides:

  • New Construction — Add custom constructions with materials, categories, and unlock conditions
  • New Armor — Add custom armor recipes with crafting stations and materials
  • Buildings Maintainer — Restore 1.2-removed constructions, apply string table imports
  • Armor Maintainer — Restore BWG colour variants, unlock sandbox items for campaign
  • Localization — PO/CSV conversion and pak packaging
  • Recipes — Auto-link colour variants to base recipes

First Run & Game Extraction

On first launch:

  1. Game Path Dialog — Select game installation (Steam, Epic Games, or custom). Auto-detects known locations. Saved to config.ini [Game].
  2. Extraction — Uses retoc to extract .uasset files from the game's IoStore paks, then UAssetGUI to convert to JSON. The manifest (data/extraction_manifest.ini) defines 11 DataTables to extract.

Extracted files serve as the vanilla baseline for Build. Extraction only runs when files are missing.

Extracted DataTables

  • DT_Constructions, DT_ConstructionRecipes (Building)
  • DT_ItemRecipes, DT_Armor, DT_Weapons, DT_Items, DT_Consumables, DT_Ores, DT_Tools (Items)
  • DT_CategoryTags (Tech Data)
  • DT_Loot (Character/AI)

Construction Workflow

Adding a new construction creates three per-item files:

  1. Tobis_json/Architecture/{tag}.json — Display name and description
  2. Tobis_json/DT_Constructions/{tag}.json — Definition (asset, icon, category, imports)
  3. Tobis_json/DT_ConstructionRecipes/{tag}.json — Recipe (materials, flags, unlock)

Tag format: {UserName}Pack_{Name}_{Letter} where the letter (A-Z) is auto-assigned.

Per-Item File Format (DT row)

{
    "NameMap": ["TobiPack_AleKeg", "/Game/path/..."],
    "Imports": [{"Package..."}, {"Texture2D..."}],
    "Row": { "Name": "TobiPack_AleKeg", "Value": [...] }
}

Per-Item File Format (Architecture)

{
    "Entries": [
        ["TobiPack_AleKeg.Name", "Ale Keg"],
        ["TobiPack_AleKeg.Description", "A keg of ale"]
    ]
}

Armor Workflow

Adding a new armor recipe creates one per-item file:

  • Tobis_json/DT_ItemRecipes/{armor_tag}.json

Available armor tags come from data/templates/MoreArmor/Armor.json. Items with existing per-item files are excluded from the dropdown.

Build Process

Build Combined Files runs combine_all():

  1. For each table (Architecture, DT_Constructions, DT_ConstructionRecipes, DT_ItemRecipes):
    • Load vanilla base from game_extract/uassetgui/
    • Read all per-item files from Tobis_json/{table}/
    • Merge NameMap, append rows, reindex imports (DT_Constructions)
  2. Write to TobisMod/json_data/{game_path}.json

Architecture uses an empty scaffold since it's a mod-only string table.

Maintainer Tabs

After Build, Maintainer tabs patch TobisMod/json_data/ in place:

Buildings Maintainer

  1. Restore Constructions — Re-enables 33 constructions removed in patch 1.2
  2. Update Mod — Applies string table imports to DT_Constructions

Armor Maintainer

  1. Restore BWG — Re-enables White/Black/Gold colour variants
  2. Sandbox to Campaign — Unlocks 21 sandbox-exclusive items for campaign

Localization Pipeline

  1. PO to CSV — Converts PO translation files to CSV
  2. CSV to PO — Converts back for translator editing
  3. Pak Locres — Packages CSVs into .pak using UnrealPak

Supported: English (source), German, Spanish, French.

File Formats

All JSON files use UAssetAPI serialization format:

  • DataTable — Exports[0].Table.Data[] array of row objects with Name key
  • Architecture — Exports[0].Table.Value[] array of [key, value] pairs
  • NameMap — String identifiers used by the asset
  • Imports — External asset references with negative index linking

Glossary

DataTable
UE4 data structure storing typed rows. Exported as JSON by UAssetGUI.
IoStore
UE4 packaging format (.ucas/.utoc). Extracted by retoc.
Per-item file
Single JSON in Tobis_json/ representing one custom item.
Vanilla base
Extracted game DataTable from game_extract/uassetgui/.
Combined file
Build output: vanilla + per-item rows merged at TobisMod/json_data/.
BWG
Black/White/Gold colour variants of cosmetic armour.
retoc
IoStore to legacy .uasset converter.
UAssetGUI
.uasset to JSON converter (uses VER_UE4_27).
