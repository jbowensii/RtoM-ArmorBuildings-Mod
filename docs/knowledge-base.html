Project Overview

This project is a content mod for The Lord of the Rings: Return to Moria, built on Unreal Engine 4.27. It adds:

  • Cosmetic armour sets — craftable armour pieces themed after LotR factions (Gondor, Rohan, Erebor, Khazad-dûm, Eregion, Iron Hills, etc.).
  • 28+ building/construction packs — walls, floors, doors, decorations, lamps, banners, and more contributed by the modding community.
  • Multi-language localisation — English, German, Spanish, and French.

The mod works by replacing and extending DataTable assets in the game's pak files. Asset editing is done through JSON exports (via UAssetGUI / UAssetAPI), and final distribution uses IoStore .pak / .ucas / .utoc archives.

Configuration System

All machine-specific paths live in config.ini at the project root. This file should not be committed to git — each contributor sets their own paths once.

config.ini Sections

SectionKeyDescription
[Paths]ProjectRootAbsolute path to this repository
[Paths]UE4RootUE4.27 installation directory
[Localization]SourcePOTemplate PO file (relative to Localization/)
[Localization]TargetLangLanguage code to process (de, es, fr)
[Localization]PakFileNameOutput .pak filename

config_loader.py API

from config_loader import cfg

cfg.project_root                   # "C:/Users/.../RtoM-ArmorBuildings-Mod"
cfg.ue4_root                       # "C:/Program Files/Epic Games/UE_4.27"
cfg.localization["target_lang"]    # "de"
cfg.path("Localization", "en")     # absolute path to Localization/en/
cfg.ue4_path("Engine", "Binaries") # absolute path inside UE4 install

Script Reference

PoToCSV.py

Purpose: Export a PO translation file to CSV so translators can work in a spreadsheet.

Input: Localization/{lang}/Game.po

Output: Localization/{lang}/Game_{lang}.csv (UTF-8 with BOM for Excel)

Run: python Localization/PoToCSV.py

CSVTOPo.py

Purpose: Merge completed CSV translations back into a PO file.

Input: Source PO template + Localization/{lang}/Game_{lang}.csv

Output: Localization/{lang}/Game.po (updated with translations)

Run: python Localization/CSVTOPo.py

autoWhiteBlackBold.py

Purpose: Auto-configure colour-variant armour recipes for discovery-based unlocking.

Input: modified-json/Moria/Content/Tech/Data/Items/DT_ItemRecipes.json

Output: Same file, modified in-place.

Run: python modified-json/autoWhiteBlackBold.py

PakLocres.bat

Purpose: Package localisation files into a compressed .pak for distribution.

Run: Localization\PakLocres.bat (Windows only)

Data Formats

UAssetAPI JSON

The JSON files in modified-json/ are serialised using UAssetAPI's JSON export format. Key structural elements: 

{
  "Imports": [...],          // External object references
  "Exports": [               // The actual data
    {
      "Table": {
        "Data": [            // Array of DataTable rows
          {
            "Name": "RowName",
            "Value": [...]   // Ordered array of property values
          }
        ]
      }
    }
  ]
}
Important: Properties in Value arrays are accessed by numeric index, not by name. Index positions are stable within a game version but may shift after game updates. If scripts produce unexpected results after a patch, re-export a clean DataTable and verify the indices.

PO Files (Portable Object)

Standard GNU gettext format used by UE4's localisation system:

msgctxt "StringTable,Key"
msgid   "English source text"
msgstr  "Translated text"

Paklist.txt

Consumed by UnrealPak.exe. Each line maps a source file on disk to its mount path inside the pak: 

"absolute/path/to/file.locres" "../../../relative/mount/path.locres"

Workflow: Localization

  1. Export — Run PoToCSV.py to create a CSV from the current PO file.
  2. Translate — Send the CSV to a translator or edit in Excel/Google Sheets. Fill in the Translation column.
  3. Import — Run CSVTOPo.py to merge translations back into the PO.
  4. Convert — Use UE4's UnrealLocres or equivalent tool to compile the PO into a .locres binary.
  5. Package — Run PakLocres.bat to bundle all .locres files into a distributable .pak.

Workflow: Recipe Automation

  1. Add new armour base recipes to DT_ItemRecipes.json via UAssetGUI.
  2. Create _White_, _Black_, _Gold_ colour variants with UnlockType = Manual.
  3. Run autoWhiteBlackBold.py — it finds every colour variant, changes the unlock type to DiscoverDependencies, and links it to the base recipe.
  4. Re-import the JSON back into the .uasset via UAssetGUI, then repack.

Workflow: Pak Packaging

  1. Edit JSON assets as needed.
  2. Use UAssetGUI to import JSON back into .uasset files.
  3. Use retoc to convert legacy .uasset files into IoStore format (.pak / .ucas / .utoc).
  4. Copy the resulting pak to the game's mod folder: [GameInstall]/Moria/Content/Packs/~mods/

Glossary

TermDefinition
DataTableUE4 asset type that stores tabular data (like a database table). Prefixed DT_.
IoStoreUE4.26+ container format (.ucas/.utoc) that replaces traditional .pak for faster loading.
.locresUE4 binary localisation resource compiled from PO files.
PO / Portable ObjectGNU gettext text format for translations; human-readable and diffable.
retocCommunity tool to repack UE4 assets into IoStore format.
UAssetAPI.NET library for reading/writing UE4 .uasset files; exports JSON.
UAssetGUIGUI front-end for UAssetAPI.
Blueprint (BP_)UE4 visual scripting asset; in this project, exported as JSON.
DiscoverDependenciesUE4 recipe unlock mode: the recipe unlocks automatically when the player discovers its dependency item.
PakUE4 archive file (.pak) containing game assets.
~mods folder[GameInstall]/Moria/Content/Packs/~mods/ — where mod paks are placed.
